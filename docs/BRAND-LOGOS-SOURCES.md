# Official brand logo sources

The homepage brand links use the manufacturers' original logo artwork, rasterized directly from official SVG/WebP sources to lossless WebP at three times each source's intrinsic dimensions. The full artwork remains inside the source canvas; no logo was redrawn or cropped. John Deere's official sprite uses the green horizontal lockup shown on its site (`#green` group, 192×36 source viewBox).

| Brand | Official asset source | Logo file |
| --- | --- | --- |
| Bosch | [Bosch media asset](https://www.bosch-presse.de/pressportal/de/media/res/gfx/bosch-invented-for-life.svg) | `public/assets/brand-bosch.webp` |
| Delphi | [Delphi official site logo SVG](https://www.delphiautoparts.com/ResourcePackages/Delphi/dist/a1d6c1389a3f6b5a43bd.svg) | `public/assets/brand-delphi.webp` |
| DENSO | [DENSO Global site](https://www.denso.com/global/en/) — the logo SVG is embedded in the site's visible header | `public/assets/brand-denso.webp` |
| John Deere | [John Deere official site logo SVG](https://cdn-ux.deere.com/brand-foundations/2.0.0/logos/jd-logo.svg#green) | `public/assets/brand-john-deere.webp` |
| VDO | [VDO official site logo SVG](https://www.vdo.com/media/vmzkhff3/logo.svg) | `public/assets/brand-vdo.webp` |

Accessible image names preserve each brand's name, and each logo remains inside its existing link to `/brands/<brand>/`.
