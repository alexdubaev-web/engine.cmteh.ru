# Проверка Signum AI Checker — 10 ноября 2026 года

На приложенном отчёте для `engine.cmteh.ru` показано 70/100. В разделе Agent Discovery & Readability отмечены два пункта: отсутствует `/llms.txt`, а для Markdown доступен только HTML. Остальные снимки из checksite.ru относятся к отдельным SEO и правовым проверкам.

Для этих двух замечаний генератор сайта публикует компактный `/llms.txt` с курируемыми ссылками и UTF-8 `index.md` рядом с каждой обычной HTML-страницей, кроме страницы 404. HTML указывает на Markdown alternate и на индекс описания. Markdown берётся из уже подготовленного основного содержимого страницы; цены, артикулы, списки, таблицы и исходящие ссылки не переписываются. Apache и demo worker явно отдают Markdown как `text/markdown; charset=utf-8` и помечают его `noindex, follow`.

`llms.txt` — предлагаемое сообществом соглашение для облегчения навигации по сайтам, а не требование Google. Google сообщает, что специальных AI-файлов или отдельной оптимизации для AI Overviews/AI Mode не требуется; стандартные правила поисковой доступности и полезности контента остаются в силе. Добавление файлов не гарантирует рост цитирований, трафика, ранжирования или результата Signum. Оценка 70/100 взята только из приложенного снимка; новый результат не измерялся.

Источники: [llms.txt proposal](https://llmstxt.org/), [Google Search guidance on AI features](https://developers.google.com/search/docs/appearance/ai-features).
