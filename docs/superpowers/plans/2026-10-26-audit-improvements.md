# Исправления по результатам аудита

Пользователь разрешил выполнить все улучшения, не требующие его присутствия. Работа в отдельной копии /workspace/engine-audit; без публикации, реальных заявок и выдуманных коммерческих фактов.

1. Поиск: русские алиасы, независимые токены, артикулы с разделителями; тесты реального обработчика.
2. Подбор: контекст карточки, запрос из пустой выдачи, явная отправка фотографий на существующий email, проверка контекста в payload.
3. Аналитика: события только после согласия, без контактов/комментариев/поисковых строк; whitelist campaign-параметров, проверки отказа и отзыва согласия.
4. Backend: дешёвая проверка готовности, индексы, CLI контроль возраста очереди и код возврата для мониторинга, проверки SQLite и existing PHP tests.
5. Остатки: по уточнению владельца считаются актуальными до следующего импорта; срок давности не вводить. Проверить сохранение количества и статуса во всех форматах.
6. SEO: отдельная страница форсунок Bosch с реальным ассортиментом, ItemList, ссылками из категории/бренда и sitemap. Подготовить товарный фид на основе утверждённых владельцем актуальных остатков.
7. Коммерческие сведения: показать существующие контакты/условия ближе к действию, оставить состояние, гарантии, НДС в цене и совместимость неподтверждёнными до реальных данных.
8. Полная сборка preview/production, тесты Node/Python/PHP, ревью diff; отчет о сделанном и внешних шагах.
