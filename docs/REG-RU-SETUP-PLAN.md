## Сервер

1. В доверенном Shell-клиенте ISPmanager получить отпечаток host key и сверить его
   с ожидаемым значением у владельца. Затем добавить отдельный публичный ключ через
   панель ISPmanager. При SSH-подключении повторно сверить отпечаток; проверку host
   key не отключать и при неожиданном значении остановиться.
2. Read-only: pwd/realpath, только каталоги engine.cmteh.ru, PHP CLI/расширения,
   наличие config.php без раскрытия его содержимого, права и API.
3. Проверить причину 404 /api/config.php. Не исправлять её по предположению.
4. Перед изменениями создать закрытую резервную копию затрагиваемых файлов.
5. Создать отдельную MySQL-базу/пользователя utf8mb4. Подтвердить точные имена
   и host. Заполнить закрытый config.php и создать ключ без вывода секрета.
6. Миграция и check при выключенном приёме. Настроить SMTP с паролем приложения,
   введённым пользователем в закрытый конфиг; проверить TLS и доставку.
7. Включить HTTP → HTTPS только для engine.cmteh.ru; повторить HTTP-проверки.
8. Установить cron с проверенными абсолютными путями к PHP и console.php.
9. Подтвердить инфраструктуру, сроки, обработчиков и утверждение документов;
   синхронно обновить текст согласия, его версию и HTML-формы.
10. Только после этого включить приём и проверить заказ с контактом владельца.

## Условия остановки зависимого шага

- Нет доверенного отпечатка или публичный ключ ещё не добавлен: не подключаться по SSH.
- Нет точных данных базы/SMTP: не выдумывать их, продолжать независимые проверки.
- Не подтверждены инфраструктура/документы: не включать приём.
- Неожиданные данные или изменения на сервере: сохранить их и пересмотреть план.
