# Статьи СМ ТЕХНО

[Единое обязательное правило работы со статьями](ARTICLE_STANDARD.md) содержит
все требования к исследованию проблем аудитории, связи с каталогом, выбору темы,
фактам, тексту, навыкам, изображениям, ссылкам, проверкам и публикации.
Перед работой его читает любой агент, включая ежедневного автора.

Основной принцип владельца: **исследованная проблема людей + реальная связь
с действующим каталогом СМ ТЕХНО**. Изучение источников и анализ нескольких тем
предшествуют написанию; затем `seo-content` и редактура через `humanize-writing`.

Семантика и история измерений: [семантическое ядро](../seo/semantic-core/README.md).
Для изменения карточек дополнительно обязателен [товарный стандарт](PRODUCT_STANDARD.md).
Приёмка обычного ежедневного выпуска и действующие разрешения описаны в едином правиле.
