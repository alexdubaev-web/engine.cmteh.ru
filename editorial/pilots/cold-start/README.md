# Редакционный пилот холодного запуска

Пилот не подключён к `data/articles.py` и расположен вне `dist` и `release-ru`. Текст оригинала хранится в `article.md`; `index.html` — локальная верстка для просмотра.

Обложка `cover.webp`: 1400 × 933 px, 105 520 байт. Файл проверен визуально на ширине 1440 и 390 px; сжатие WebP не дало заметных артефактов. В HTML заданы размеры, альтернативный текст и подпись с указанием генеративного происхождения и вариативности конструкции.

Локальная проверка сборки из корня репозитория: `python build.py`. Для просмотра из корня репозитория запустите `python -m http.server 8765 --bind 127.0.0.1`, затем откройте `http://127.0.0.1:8765/editorial/pilots/cold-start/`. Пилот использует относительные ссылки на `public/assets/style.css`, реально существующие Manrope 400/600/800 и favicon. В нём нет JavaScript, сторонних зависимостей, канонического URL или schema публикации; в robots задано `noindex,nofollow`.
