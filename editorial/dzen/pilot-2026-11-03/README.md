## Как разместить

Откройте редактор статьи в своём канале. Заголовок перенесите в поле названия,
остальной текст из `article.md` либо открытого `article.html` в тело. Загрузите
соответствующую обложку. Перед публикацией проверьте абзацы, таблицу во втором
материале, ссылки и кадрирование обложки в доступном предпросмотре. Если редактор
не сохраняет таблицу, используйте перечисление с теми же восемью критериями.
Служебные документы `research.md` и `validation.json` в публикацию не переносятся.

Автоматически открыть канал не удалось из-за ограничения безопасности браузера.
Доступ к управлению каналом и актуальные требования платформы не подтверждены.
Пакет не заявляет соответствие непроверенным правилам монетизации или рекламы.

## Ссылки и результат

Во всех ссылках используются `utm_source=dzen`, `utm_medium=referral`,
`utm_campaign=dzen_pilot_20261103`. Значения `utm_content` разделяют статьи:
`multi_machine_order`, `compare_offers`, `receiving_handoff`.
Ссылки ведут на существующие страницы с HTTPS-canonical без UTM.

После ручной публикации сохраните URL и фактическую дату каждой статьи. Оценивайте
чтение по статистике канала, переходы на сайт по UTM в Метрике, а заявки по отдельно
проверенному учёту успешной отправки формы. Клик по кнопке сам по себе не равен
принятой заявке. Сейчас статистика новых материалов отсутствует.

Тексты дают полный ответ внутри статьи. Они не дублируют статьи сайта и не требуют
перехода для получения обещанного ответа. Ссылки уместны для следующего действия.
Гарантий охватов, индексации и продаж пакет не содержит.
