## Что должно заработать

Покупатель видит реквизиты продавца на любой странице и понимает, что корзина отправляет запрос; условия согласовываются перед оплатой. Тексты уже существующего согласия ясно называют cookie. Главная получает более короткие предметные метатеги. Отчёт объясняет все замечания 11 скриншотов с доказательствами.

## Критерии приёмки

- [x] Главная получает более короткие уникальные title/description с сохранением смысла и бренда, без нерелевантных SEO-ключей.
- [x] Общий footer явно содержит данные продавца из commerce.json, экранированные и читаемые на мобильном, плюс ссылку на условия.
- [x] Existing /delivery/ содержит #terms с условиями существующего B2B запроса и оговоркой о справочных ценах/непубличной оферте; никаких придуманных сроков, гарантий, возвратов.
- [x] В существующей политике точно назван 152-ФЗ; цели и сроки обработки, текст/версия согласия неизменны.
- [x] Баннер и кнопка настроек явно называют cookie, поведение согласия и аналитики не изменено. Если меняется название ссылки, синхронизировать упоминание в privacy policy.
- [x] docs/CHECKSITE-2026-11-09.md разбирает все группы скриншотов: действительные проблемы, false positives, optional prefetch, arbitrary thresholds, nausea, irrelevant query, unmeasured backlink/rank fields; источники и фактические результаты, без объявления юридического соответствия или поискового роста.
- [x] Затронутые проверки из interfaces проходят; не добавлять тесты на текст/разметку для этих обратимых правок. Целевую визуальную проверку выполняет ведущий.
