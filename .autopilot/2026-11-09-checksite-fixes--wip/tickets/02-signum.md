## Критерии приёмки

- [ ] /llms.txt валиден по предложению формата, компактен, содержит только реальные данные и ссылки на созданные Markdown основных разделов.
- [ ] Все non404 HTML имеют same-dir index.md с полезным содержанием main, canonical-ссылкой, заголовками, рабочими ссылками и сохранёнными фактами/таблицами; нет форм/скриптов/баннеров/JSON.
- [ ] HTML сообщает Markdown alternate и llms describedby; canonical/robots/Sitemap HTML сохраняются по назначению.
- [ ] .md отвечает правильным MIME/UTF-8/noindex через Apache, без изменения существующих redirects/404/API/CSP.
- [ ] Осмысленные новые проверки и existing affected SEO/catalog/Apache checks проходят; прежний Checksite набор без изменений не гоняется повторно.
- [ ] Документ кратко объясняет две рекомендации Signum и ограничения балла; никакой гарантии AIвидимости.
- [ ] Ведущий завершает source PR и guarded deployment с подтверждением публичного результата и сохранности закрытого состояния.
