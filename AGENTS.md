# Правила проекта

## Изображения для сайта

Все новые генерируемые растровые изображения для сайта, включая обложки статей, должны быть оптимизированы для веб и поставляться в формате WebP. Подбирайте разрешение под фактический размер размещения, проверяйте качество после сжатия и задавайте размеры и содержательный alt в HTML. Исходники PNG храните отдельно от публичных материалов.

Для статей соблюдайте также редакционные правила в [editorial/README.md](editorial/README.md).
